# HostelBuddy 🏨📱

**HostelBuddy** is a modern, responsive web application for hostel students and hostellers to share rides, food runs, grocery shopping, airport/station drops, and daily campus outings.

---

## ✨ Features

- **Authentication System**: Secure Sign In & Registration with student name, email, hostel block (Block A, Block B, Girls Hostel 1/2, PG Annex), and room number.
- **Header Profile**: Dynamic user avatar initials and hostel room display.
- **Hero Dashboard**: Live metrics tracking Active Requests, Buddies Paired, and Cab Fares Split.
- **Search & Category Filters**:
  - ✈️ Transit & Airport
  - 🛍️ Malls & Shopping
  - 🍔 Cafes & Food
  - 🎬 Movies & Outing
  - 📚 College & Exams
  - 🏥 Medical & Urgent
- **Transport Modes**: Cab/Auto Share, Bike/Scooty, Bus/Metro, Walking Group.
- **Interactive Modals**: Post travel requests, view request details, and simulate live room-to-room pings.
- **Dark & Light Mode**: Smooth theme toggle with persistent state.
- **Zero Fake Data**: Clean real-user request feed.

---

## 🛠️ Built With

- **HTML5** & **CSS3** (Custom Design System with CSS variables and glassmorphism)
- **JavaScript (ES6)** (State engine & LocalStorage persistence)
- **FontAwesome 6** Icons & **Google Fonts** (Plus Jakarta Sans)
